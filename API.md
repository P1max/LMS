# REST API системы управления обучением

## Общие сведения

Базовый адрес: `http://localhost:3000/api/v1`.

Данные хранятся в массивах Node.js в памяти процесса. После перезапуска сервера начальные демонстрационные данные восстанавливаются. Тела запросов на создание и изменение передаются в формате JSON с заголовком `Content-Type: application/json`.

Успешные ответы со списком имеют вид `{ "count": 2, "data": [...] }`, ответы с одной записью – `{ "data": {...} }`, ошибки – `{ "error": "Описание ошибки" }`.

## Коды ответа

| Код | Значение |
| --- | --- |
| 200 | Запрос выполнен; запись или список возвращены |
| 201 | Ресурс создан; адрес созданной записи передан в заголовке `Location` |
| 204 | Ресурс удалён; тело ответа отсутствует |
| 400 | Некорректный идентификатор, параметры или тело запроса |
| 404 | Ресурс не найден |
| 409 | Конфликт: электронная почта уже занята или у курса ещё есть занятия |
| 500 | Внутренняя ошибка сервера |

## Курсы

Курс содержит `title`, `description`, `teacher`, положительное числовое значение `durationHours` и статус `draft`, `published` либо `archived`. Статус при создании необязателен; по умолчанию устанавливается `draft`.

| Метод | URL | Назначение | Успех |
| --- | --- | --- | --- |
| GET | `/courses` | Список; фильтры `status`, `search` | 200 |
| GET | `/courses/{id}` | Курс по идентификатору | 200 |
| POST | `/courses` | Создать курс | 201 |
| PUT | `/courses/{id}` | Полностью заменить поля курса | 200 |
| PATCH | `/courses/{id}` | Изменить переданные поля | 200 |
| DELETE | `/courses/{id}` | Удалить курс без занятий | 204 |

Пример создания:

```json
{
  "title": "Система управления обучением",
  "description": "Расписание, оценки и посещаемость",
  "teacher": "Елена Волкова",
  "durationHours": 40,
  "status": "draft"
}
```

Пример ответа `201 Created`:

```json
{
  "data": {
    "id": 3,
    "title": "Система управления обучением",
    "description": "Расписание, оценки и посещаемость",
    "teacher": "Елена Волкова",
    "durationHours": 40,
    "status": "draft",
    "createdAt": "2026-10-09T10:00:00.000Z",
    "updatedAt": "2026-10-09T10:00:00.000Z"
  }
}
```

Для `PUT` обязательны название, описание, преподаватель и продолжительность. Для `PATCH` достаточно передать одно или несколько полей. Неизвестные поля и неверный статус отклоняются с кодом 400. Нельзя удалить курс, к которому привязаны занятия: возвращается 409.

## Студенты

Студент содержит обязательные непустые `fullName`, `email` и `group`. Адрес электронной почты проверяется на простой формат и уникальность без учёта регистра.

| Метод | URL | Назначение | Успех |
| --- | --- | --- | --- |
| GET | `/students` | Список; фильтры `group`, `search` | 200 |
| GET | `/students/{id}` | Студент по идентификатору | 200 |
| POST | `/students` | Создать студента | 201 |
| PUT | `/students/{id}` | Полностью заменить данные студента | 200 |
| PATCH | `/students/{id}` | Изменить переданные поля | 200 |
| DELETE | `/students/{id}` | Удалить студента | 204 |

Пример создания:

```json
{
  "fullName": "Иван Петров",
  "email": "ivan.petrov@lms.local",
  "group": "ИТ-21"
}
```

Пример ответа `201 Created`:

```json
{
  "data": {
    "id": 3,
    "fullName": "Иван Петров",
    "email": "ivan.petrov@lms.local",
    "group": "ИТ-21",
    "createdAt": "2026-10-09T10:00:00.000Z",
    "updatedAt": "2026-10-09T10:00:00.000Z"
  }
}
```

Повторное использование электронной почты возвращает 409. В ресурсе студентов нет пароля: учётные данные не принимаются и не сохраняются этим API.

## Занятия

Занятие содержит `courseId`, `title`, `description`, положительный целый `orderNumber` и `durationMinutes`. `courseId` должен указывать на существующий курс.

| Метод | URL | Назначение | Успех |
| --- | --- | --- | --- |
| GET | `/lessons` | Список; фильтры `courseId`, `search` | 200 |
| GET | `/lessons/{id}` | Занятие по идентификатору | 200 |
| POST | `/lessons` | Создать занятие | 201 |
| PUT | `/lessons/{id}` | Полностью заменить данные занятия | 200 |
| PATCH | `/lessons/{id}` | Изменить переданные поля | 200 |
| DELETE | `/lessons/{id}` | Удалить занятие | 204 |

Пример создания:

```json
{
  "courseId": 1,
  "title": "Основы CSS",
  "description": "Селекторы, свойства и каскад",
  "orderNumber": 2,
  "durationMinutes": 90
}
```

Пример ответа `201 Created`:

```json
{
  "data": {
    "id": 3,
    "courseId": 1,
    "title": "Основы CSS",
    "description": "Селекторы, свойства и каскад",
    "orderNumber": 2,
    "durationMinutes": 90,
    "createdAt": "2026-10-09T10:00:00.000Z",
    "updatedAt": "2026-10-09T10:00:00.000Z"
  }
}
```

## Общие правила проверки

- идентификаторы в URL должны быть положительными целыми числами;
- `POST` и `PUT` проверяют обязательные поля и типы значений;
- `PATCH` проверяет все переданные поля и не принимает пустое тело;
- лишние свойства не сохраняются и отклоняются с кодом 400;
- при неизвестном идентификаторе возвращается 404;
- некорректный JSON возвращает 400;
- `DELETE` с кодом 204 возвращает пустое тело.

## Проверка запросов

Примеры запросов для расширения REST Client VS Code находятся в `requests.http`. Порядок демонстрации: запросы списка и получения, создание записи, `PUT`, `PATCH`, удаление, затем повторный `GET` для проверки 404. В сценариях создания предполагается свежий запуск сервера, поэтому новые идентификаторы начинаются с 3; при повторном выполнении используйте идентификатор из ответа `Location`.
